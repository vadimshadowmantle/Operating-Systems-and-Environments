# ДЗ 07. Создание демонов

**Задание:** написать Bash-скрипт, который раз в несколько секунд пишет в системный журнал (`logger`), что он активен, и отмечает запуск и завершение по `SIGTERM`/`SIGINT` (`trap`). Оформить его как демон `systemd`: сначала пользовательский сервис в `~/.config/systemd/user/`, затем системный в `/etc/systemd/system/`; запускать и останавливать через `systemctl` и проверять журнал.

**Итог:** в современном Debian нет текстового `/var/log/syslog`, поэтому сообщения демона смотрел через `journalctl`.
