# ДЗ 09. Доклад: FreeBSD

**Задание:** доклад на 5–7 минут с презентацией (5–7 слайдов) об одной операционной системе на выбор — её истории и особенностях.

**Тема:** FreeBSD — происхождение от BSD UNIX и разработка системы как единого целого, файловая система ZFS (контрольные суммы, снимки, boot environments), изоляция через Jails, лицензия BSD (Netflix, PlayStation), кому и зачем нужна FreeBSD.
