# ДЗ 01. Создание снимков виртуальной машины

**Задание:** сделать снимок ВМ в VirtualBox, «сломать» систему патчем Бармина (`rm -rf --no-preserve-root /`), убедиться, что ОС больше не загружается, и восстановить её из снимка.

**Итог:** после команды система не загрузилась (не найден `/boot/grub/i386-pc/normal.mod`), откат к снимку вернул ВМ в рабочее состояние. Вывод — перед рискованными действиями нужно делать снимок.
